# CASHEWTRACER
A lightweight cybersecurity toolkit for IP intelligence, network analysis, and digital reconnaissance.
## Network Intelligence & IP Analysis Toolkit

CASHEW TRACER is a lightweight Python-based terminal tool for gathering network intelligence through a clean Linux-style interface.

## Features

- Public IP detection
- Private IP detection
- IP geolocation
- ISP and ASN lookup
- Reverse DNS lookup
- Website → IP extraction
- Phone number country lookup
- JSON report export
